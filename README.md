# Описание Telegram-бота для управления заявками и расходными материалами

## Цель проекта
🔹 Автоматизация учета заявок на расходный материал.

🔹 Контроль остатков и своевременное пополнение.

🔹 Упрощение взаимодействия пользователей и администраторов.

🔹 Логирование всех действий для прозрачности (для руководителя).

## Административные функции
### Управление инфраструктурой
 • 📌 Добавление объектов (здания, кабинеты).

 • 🗑️ Удаление объектов.

### Управление запасами
 • ➕ Пополнение (добавить 50 единиц).

 • ⚠️ Установка точек заказа и резерва (неснижаемого запаса).

### Черный список
 • 🚫 Блокировка пользователей (ограничение доступа зарегистрированных пользователей).


## Автоматизированный планировщик
### Расписание уведомлений
 • 📅 Пн-Пт: отправка отсортированного по зданиям списка заявок, поданных до 10:00 и 13:00 (настраивается).

 • 📧 Дублирование на email.

### Контроль запасов
 • 🔴 Автоуведомление при критическом минимуме (что необходимо пополнить запасы).

 • 📦 Заявки, созданные в выходные, накапливаются и встают на расписание к отправке в понедельник утром (в 10:00).


## Пользовательские функции
### Регистрация
 • ✅ Только для доверенных пользователей (как пример, регистрация в закрытом контуре).

### Оформление заявки
 1 Выбор здания → кабинета → Подтверждение.

 2 Лимит для пользователя: 1 заявка/день (настраивается).

 3 Лимит для кабинета - уведомление на случай, если коллега успел подать раньше

### Дополнительно
 • ⭐ Избранный объект (крайний выбор) для повторного быстрого доступа.

 • 📊 Просмотр остатков склада (пользователь не видит, что есть неснижаемый запас).

 • 📝 Доступ к сводному списку заявок текущего тайм-слота


## Техническая реализация
### Стек технологий
 • Backend: Python + Aiogram (Telegram API).

 • База данных: SQLite, PostgreSQL (хранение объектов, заявок, логов).

 • Планировщик: APScheduler.

 • Почта: SMTP.


## Логирование и наполнение базы
### Что логируется?
 • 📝 Все заявки, регистрация и попытки зарегистрироваться.

 • 🔄 Изменения запасов.

 • ⚠️ Действия админов и пользователей.
